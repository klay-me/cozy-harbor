# 暖港 Cozy Harbor

一个 3渲2 卡通风格的城市建造小游戏，玩法参考《纪元 1800》前期：修路、盖房、搭生产链、满足居民需求、升级人口阶层。

纯网页实现：TypeScript + Vite + Three.js，没有用游戏引擎。

## 运行

```bash
npm install
npm run dev      # 本地开发，打开终端里显示的地址
npm run build    # 打包到 dist/
```

推送到 `main` 分支后，`.github/workflows/pages.yml` 会自动构建并发布到 GitHub Pages。第一次需要在仓库 Settings → Pages 里把 Source 设为 **GitHub Actions**。

## 操作

| 操作 | 电脑 | 手机 |
|---|---|---|
| 移动镜头 | 右键（或左键）拖动地面 / WASD | 单指拖动 |
| 转动视角 | 按住中键拖动 / 按住 Q E | 双指旋转 |
| 缩放 | 滚轮 | 双指捏合 |
| 修路 | 选道路后按住拖动 | 同左 |
| 建造 | 选建筑后点击地面 | 点一次预览，再点同一处确认 |
| 取消 | 右键单击 / Esc | 点"选择" |
| 暂停 | 空格 | 顶部"暂停" |

快捷键：`R` 道路、`H` 农舍、`X` 拆除。游戏每 30 秒自动保存到浏览器本地。

转动方式默认是"转动视角"（镜头原地转头），菜单里可以改成"绕画面中心旋转"。

## 玩法与数值

所有数值都在 [`src/sim/data.ts`](src/sim/data.ts)，改那一个文件就能调平衡。

### 人口阶层

| 阶层 | 每户人数 | 税收（每人每分钟） | 需要的货物（每人每分钟） | 需要的服务 |
|---|---|---|---|---|
| 农民 | 4 | 1.2 金币 | 鱼 0.075 | 集市 |
| 工人 | 8 | 2.6 金币 | 鱼 0.075、面包 0.05 | 集市、酒馆 |

- 每户的满意度 = 已满足需求的比例。实际住户数 = 上限 × 满意度，人口逐步增减。
- 税收 = 人数 × 税率 × (0.4 + 0.6 × 满意度)。
- 农舍满足全部需求、住满后，花 50 金币 + 6 木板升级为工人住宅。升级后这户人从农民劳动力变成工人劳动力。

### 生产链

```
伐木场 ──木材──▶ 锯木厂 ──木板──▶ 建造
渔场 ──鱼──▶ 农民、工人
麦田 ──小麦──▶ 磨坊 ──面粉──▶ 面包房 ──面包──▶ 工人
```

| 建筑 | 尺寸 | 造价 | 维护/分 | 劳动力 | 周期 | 产出/分 | 特殊条件 |
|---|---|---|---|---|---|---|---|
| 伐木场 | 2×2 | 50 金 2 板 | 5 | 农民 4 | 15 秒 | 4 木材 | 半径 3 内树木越多效率越高 |
| 锯木厂 | 2×2 | 100 金 4 板 | 10 | 农民 6 | 15 秒 | 4 木板 | |
| 渔场 | 2×2 | 80 金 2 板 | 5 | 农民 3 | 20 秒 | 3 鱼 | 必须紧挨水边 |
| 麦田 | 3×3 | 100 金 4 板 | 10 | 农民 4 | 30 秒 | 2 小麦 | |
| 磨坊 | 2×2 | 150 金 8 板 | 15 | 工人 4 | 30 秒 | 2 面粉 | |
| 面包房 | 2×2 | 150 金 8 板 | 15 | 工人 4 | 30 秒 | 2 面包 | |
| 集市 | 2×2 | 120 金 6 板 | 10 | — | — | — | 服务半径 9 |
| 酒馆 | 2×2 | 200 金 10 板 | 20 | — | — | — | 服务半径 9 |
| 仓库 | 2×2 | 100 金 6 板 | 5 | — | — | — | 每种货物上限 +40 |
| 农舍 | 2×2 | 40 金 2 板 | — | — | — | — | |
| 道路 | 1×1 | 2 金 | — | — | — | — | |

参考配比：1 座渔场约养 40 人；1 条面包链（麦田 → 磨坊 → 面包房）约养 40 个工人。

### 时间、季节

- 一天 4 分钟（1 倍速），早上 6 点港口敲钟，夜里窗户和路灯会亮。
- 每个季节 2 天，一年 8 天，顶栏显示"第几年 · 季节 · 时间"。

| 季节 | 效果 | 画面 |
|---|---|---|
| 春 | 无 | 嫩绿、部分树开粉花 |
| 夏 | 麦田 +20% | 浓绿 |
| 秋 | 麦田 +40% | 橙红黄的树、草地泛黄 |
| 冬 | 麦田休耕，渔场 -30% | 积雪覆盖屋顶和地面，会下雪 |

### 居民

纯画面效果，不影响数值：早上 6 点上班、下午 5 点下班，白天有人去集市、酒馆、面包房，晚上街上人变少；生产出货物时会有人推车送到仓库；渔场开工时渔船出海；集市白天有人闲逛。

### 天气

天气每隔一到两分钟随机变化，过渡约 10 秒，会影响产量：

| 天气 | 效果 |
|---|---|
| 晴 / 多云 | 无 |
| 下雨 | 麦田 +25% |
| 雷雨 | 麦田 +25%，渔场停工 |
| 起雾 | 渔场 -40% |
| 下雪（仅冬季） | 伐木场 -30% |

画面上有雨丝、闪电、地面变湿、水面雨点涟漪、雾气和云量变化。

### 声音

- 背景音乐：6 首原创曲子，用真实乐器采样演奏（来源见 [CREDITS.md](CREDITS.md)），按季节、夜晚、雨天自动切换并淡入淡出：
  春《晨光小镇》、夏《夏日集市》、秋《秋收》、冬《雪落港湾》、夜《晚安》、雨《雨天》
- 环境音：海浪、风、雨、雷，白天鸟叫和海鸥，夜里蟋蟀
- 音效：建造、修路、拆除、升级、完成目标、生产、换季、早晨钟声、按钮、错误提示

菜单里可以分别调节音乐和音效音量，顶栏有一键静音。浏览器要求先点一下页面才会出声。

### 规则

- 所有建筑都要用道路连到港口或任意仓库，否则停工、没人入住。
- 劳动力按建造顺序分配，人手不够时按比例降低产量。
- 货物全城共享，存储上限 = 港口 60 + 每座仓库 40。
- 拆除返还一半造价。
- 9 个引导目标，完成后有金币或木板奖励，最后一个目标是工人达到 80 人。

## 代码结构

```
src/
  sim/        纯逻辑，不依赖渲染
    data.ts     全部数值配置
    world.ts    地图生成（海岸、河流、湖、森林、岩石）
    game.ts     建造规则、道路连通、生产、消费、人口、经济、目标、存档
  render/     Three.js 画面
    assets.ts   加载 Blender 模型，合并成带颜色、发光、树叶、染色标记的几何体
    shared.ts   全局着色参数（夜间发光、积雪、季节树叶色）和统一材质
    terrain.ts  平滑海岸线的地形、水面（岸边浪花、波纹、反光、雨点）
    env.ts      天空、日夜、季节、天气、云、雨雪、水花、闪电
    people.ts   居民、推车、渔船
    view.ts     建筑、道路、路灯、树、建造预览、选中、浮字、夜间泛光
    toon.ts     三段色阶着色和描边
    camera.ts   策略游戏镜头（转动视角 / 绕中心旋转两种模式）
    thumbs.ts   建造菜单的缩略图
  audio/
    music.ts    采样器和曲谱（旋律用级数写，伴奏自动生成）
    sound.ts    音量、环境音、音效
tools/
  models.py            用 Blender 脚本生成全部模型，导出 public/models/town.glb
  extract-samples.mjs  从音色库里抽取需要的乐器采样
  ui/         DOM 界面
  main.ts     输入和主循环
```

模拟层和渲染层分开，以后换成 Blender 做的模型，只需要改 `render/models.ts`；以后移植到 Godot，`sim/` 里的规则可以直接照搬。

## 改模型

模型全部在 `tools/models.py` 里用代码搭出来。改完运行：

```bash
uv venv --python 3.11 .blender && uv pip install --python .blender/bin/python bpy==4.5.0
.blender/bin/python tools/models.py
```

开发时打开 `#gallery`（比如 `http://localhost:5173/#gallery`）可以把所有模型排在一起看，`#gallery-snow`、`#gallery-night` 看积雪和夜景。

`#gallery-lines` 按升级线逐行比较模型，每行左侧有农舍和居民作尺度参照；半透明格子按 `data.ts` 的当前占地绘制，每格 1 单位。拖动旋转、右键平移、滚轮缩放，空格暂停动画，`R` 重置全景。画廊与游戏共用动画规则，`-pose` 保留静态摆动姿态检查。

```bash
node tools/check-models.mjs                           # 尺寸、门高、动画与烟囱基准
node tools/test/check-models.mjs                      # 检查测量与警告阈值
npm run build
python3 tools/test/gallery-shot.py fishery hospital   # 3 个全景 + 指定模型截图
```

截图保存在已忽略的 `tools/test/shots/`。截图脚本需要 Python Playwright 和 Chromium，可用 `pip install playwright && python3 -m playwright install chromium` 安装。检查脚本默认报告既有尺寸警告；加 `--strict` 会在有警告时返回失败。`XZ` 包围盒包含动画部件的静止姿态，不含描边和运动扫掠；模型名 `house` 会展开为各阶层的四种住宅。
